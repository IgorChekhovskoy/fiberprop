### Основная информация

Модуль Python, являющийся обёрткой для вычислительно сложных функций, реализованных на языке Julia. 

Структура модуля:
* Основные функции находятся в файлах calculation_dmatrix.jl, calculation_linear_step.jl, calculation_nonlinear_step.jl, structures.jl
* Потом это всё используется в файле numerical_methods.jl для реализации самого метода
* В файле general_code.jl реализованы функции, которые будет вызывать python посредством juliacall, там производится преобразование типов и копирование массивов, чтобы корректно управлять памятью
* В файле computing_module.jl всё собирается в модуль julia под названием ComputingJuliaModule. И реализуется подгрузка недостающих библиотек в julia (при первом вызове)
* Дальше в файле functions уже на python реализованы функции, которые будут вызывать соответствующие функции на julia
functions становится частью питоновского пакета julia_compute
---

Для установки пакета в интерпретатор python следует выполнить следующую команду:
```pip install absolute_path_to_setup.py/```

Тогда использовать его в коде можно, например, следующим образом:
```
from julia_compute.functions import make_iteration_julia, make_iteration_dcalc_julia

...
```

Многопоточность включена по умолчанию. Если не настроить переменную среды JULIA_NUM_THREADS, то поток выполнения будет один.

Рекомендуется установить значение переменной среды PYTHON_JULIACALL_HANDLE_SIGNALS = yes, чтобы избежать лишних предупреждений.

### Доступные функции

```make_iteration_dcalc_julia(...):```  
Один шаг численного моделирования с расчётом матрицы D (симметричное расщепление N-D-N с учётом усиления и шума).  
*глубокое копирование массивов происходит при передаче julia управления памятью  
- initial_psi: начальное поле, комплексный массив размера (n, M)
- linear_coeffs_array: матрица связи (n, n)
- self_coupling: массив (n) коэффициентов самосвязи
- noise_amplitude: double амплитуда равномерного шума, добавляемого на каждой итерации (для моделирования резонаторов)  
Возвращает следующий шаг решения.

```make_iteration_julia(...):```  
Один шаг численного моделирования без расчёта матрицы D (симметричное расщепление N-D-N с учётом усиления и шума).  
*глубокое копирование массивов происходит при передаче julia управления памятью  
- initial_psi: начальное поле, комплексный массив размера (n, M)
- D: экспонента от матрицы связи (n, n, M) или (n, n), в зависимости от дисперсии или различия ГС
- noise_amplitude: double амплитуда равномерного шума, добавляемого на каждой итерации (для моделирования резонаторов)  
Возвращает следующий шаг решения.

```calculate_short_noisefree_julia(...):```  
Численное моделирование без расчёта матриц D и D_half (симметричное расщепление D-N-D с учётом усиления и шума).  
Ускорение в 3-4 раза по сравнению с make_iteration_dcalc_julia, но без возможности отслеживать промежуточные состояния поля  
*глубокое копирование массивов происходит при передаче julia управления памятью  
- initial_psi: начальное поле, комплексный массив размера (n, M)
- D: массив (n, n, M) или (n, n) экспонента матрицы для линейного шага
- D_half: массив (n, n, M) или (n, n) экспонента матрицы для линейного полушага
- enable_pb: bool флаг, отвечающий за отображение progress bar  
Возвращает решение в конечной точке.
